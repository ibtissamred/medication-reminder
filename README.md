# Medication Reminder and Schedule Manager

## Project Overview
The Medication Reminder and Schedule Manager is a healthcare-focused web application prototype developed using Python and Flask. It helps users organize medication schedules and record the status of scheduled doses.

## Features
- Add and delete medication records
- Store dosage instructions and treatment dates
- Generate a daily medication schedule
- Mark doses as taken or missed
- View previous dose records
- Display daily medication statistics

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run
1. Install Python.
2. Install Flask by running `python -m pip install flask`.
3. Open a terminal in the project folder.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.

## Learning Outcomes
This project provided practical experience with database operations, Flask routes, form handling, HTML templates, date-based records, and web application development.

## Disclaimer
This is an educational prototype, not a clinically validated medication management system. It does not verify prescriptions or provide medical advice. Users should follow instructions from their healthcare professionals.
